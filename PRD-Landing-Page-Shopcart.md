## 2. Setup & Perubahan Struktur Proyek

### 2.1 Instalasi shadcn/ui

```bash
npx shadcn@latest init
npx shadcn@latest add button badge dropdown-menu input separator card
```

### 2.2 Struktur Folder (Dirapikan)

Struktur diringkas per section landing page — tidak dalam/nested berlebihan:

```
app/
├── page.tsx                     # Landing page — merangkai semua section di bawah
├── layout.tsx                   # Root layout (font, metadata)
├── globals.css
│
├── (routes placeholder — belum dikerjakan, hanya folder kosong + page.tsx dasar)
├── products/
│   └── page.tsx                 # placeholder "Coming soon"
├── cart/
│   └── page.tsx                 # placeholder
└── account/
    └── page.tsx                 # placeholder

components/
├── ui/                          # auto-generated by shadcn (jangan edit manual)
├── layout/
│   ├── TopBar.tsx                # baris atas: telepon, promo text, lang/location
│   └── Header.tsx                 # navbar utama (logo, menu, search, account, cart)
└── landing/
    ├── HeroBanner.tsx             # banner promo headphone
    ├── FilterBar.tsx              # baris filter (UI only)
    ├── ProductGrid.tsx            # grid pembungkus product card
    └── ProductCard.tsx            # 1 kartu produk

lib/
└── mock-products.ts              # data dummy produk untuk grid

types/
└── product.ts                    # interface Product

public/
└── header/                       # ⚠️ khusus asset desain custom kamu
    ├── pict.png
    └── (logo/icon lain menyusul dari kamu)
```

**Catatan:** Tidak membuat folder `sections/`, `hooks/`, `store/` dulu — baru ditambah saat fase berikutnya butuh (cart logic, auth, dst) supaya struktur tidak terlalu dalam di awal.

## 6. Asset Custom Header (dari Kamu)

Folder sudah disiapkan di:
```
public/header/pict.png
```

Saat komponen `Header.tsx` dibuat, logo akan mereferensikan path ini via `next/image`:
```tsx
<Image src="/header/pict.png" alt="Shopcart Logo" width={32} height={32} />
```
Silakan drop file desain kamu (logo, icon, dsb.) ke folder `public/header/` — komponen tinggal disesuaikan pathnya kalau nama file berbeda.
